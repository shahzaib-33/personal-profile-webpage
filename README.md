# Personal Profile Webpage

A clean, responsive personal profile page for Shahzaib Wakeel, built with semantic HTML and Tailwind CSS.

## Features

- Responsive layout for mobile, tablet and desktop
- Sections for About Me, Skills and Contact
- Lightweight: a single HTML file and one stylesheet, no build step

## Tech stack

HTML5, Tailwind CSS (CDN), CSS3

## Run locally

Open `index.html` in any browser.
