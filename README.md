# Personal Profile Webpage

A clean, responsive personal profile page for Shahzaib Wakeel, built with semantic HTML and Tailwind CSS.

## Features

- Responsive layout for mobile, tablet and desktop
- Sections for About Me, Skills, Projects and Contact
- Projects: Airway, an animated online clothing store ([live demo](https://shahzaib-33.github.io/airway-store/), [source](https://github.com/shahzaib-33/airway-store))
- Lightweight: a single HTML file and one stylesheet, no build step

## Tech stack

HTML5, Tailwind CSS (CDN), CSS3

## Run locally

Open `index.html` in any browser.
